# Amiri — трекер расходов в Telegram

Пишете боту `кофе 350` — расход сохранён. Категорию определяет AI.
Аккаунт — это ваш Telegram: ни регистрации, ни паролей.

**Бот:** [@amiri_expenses_bot](https://t.me/amiri_expenses_bot)
**Панель:** [expenses.veriks.com](https://expenses.veriks.com)

---

## Из чего состоит

| Папка | Что это | Стек | Инструкция |
|---|---|---|---|
| [`backend/`](backend) | Бот + REST API + база | Python, aiogram 3, FastAPI, PostgreSQL | [backend/README.md](backend/README.md) |
| [`frontend/`](frontend) | Веб-панель | React, Vite, Tailwind, Recharts | [frontend/README.md](frontend/README.md) |

Два самостоятельных приложения в одном репозитории: свои зависимости, свой
`.env`, свой `README`. Общего кода между ними нет — панель ходит в API по
HTTP. Запускать можно и по отдельности (для разработки), и вместе одной
командой (`docker compose` — см. «Деплой»).

## Что умеет

**Ввод**

- Расход одним сообщением: `кофе 350`, `350 кофе`, `такси 900 работа`
- Несколько сразу: `кофе 350, такси 900, хлеб 20` → три записи и кнопка «Отменить всё»
- Свободный текст: «потратил триста пятьдесят на кофе», «нон сад сомонӣ» — сумму достаёт AI
- Фото чека: бот читает итоговую сумму. Подпись к фото становится описанием
- Три валюты: `5$ подписка`, `500р курс`, `350с хлеб`

**Категории**

- Определяются сами: явный `#тег` → память пользователя → трёхъязычный словарь → OpenAI
- Если ничего не подошло — AI предлагает новую категорию, пользователь подтверждает одной кнопкой
- Бот учится: поправили категорию один раз — дальше это слово распознаётся мгновенно, без обращения к AI

**Отчёты**

- В боте: `/today`, `/week`, `/month` — по категориям и по дням, диаграммой прямо в чате
- В панели: круговая по категориям, столбцы по дням, произвольный период, сравнение с прошлым

**Контроль**

- Лимиты по категориям на месяц: бот предупреждает на 80% и при превышении
- Правка и удаление из бота и из панели, восстановление после удаления
- Выгрузка CSV из бота и из панели

**Интерфейс**

- Три языка: таджикский, русский, английский. Определяется автоматически, меняется в `/lang`
- Панель адаптивная, тёмная тема по настройке системы

## Как это устроено

**Бот и API — один процесс.** У них общие модели, парсер и категоризатор.
Писать их дважды значит получить два места для расхождений.

**Категория ищется от дешёвого к дорогому.** `#тег` → память пользователя →
словарь на трёх языках → OpenAI. 80–90% сообщений до AI не доходят: отвечают
мгновенно и бесплатно. Любая ошибка AI (таймаут, лимит, битый ответ) роняет
расход в «Другое», но не теряет его.

**Курс валюты фиксируется в момент записи.** Отчёт за прошлый месяц не
меняется от того, что сегодня доллар подорожал. При смене основной валюты
все суммы и лимиты пересчитываются разом — иначе итоги складывали бы рубли
с сомони.

**Данные пользователей не пересекаются.** Каждый SQL-запрос фильтруется по
`user_id`; запрос чужого расхода отдаёт `404`, а не `403` — чтобы нельзя было
проверить существование чужой записи. Это покрыто отдельными тестами.

## Как запустить локально

Понадобятся **Python 3.12+**, **PostgreSQL 14+** и **Node 20+**.
Ещё нужны токен бота и ключ OpenAI — как их получить, ниже.

### 1. Склонировать

```bash
git clone <репозиторий>
cd amiri
```

### 2. Получить токен бота

В Telegram напишите [@BotFather](https://t.me/BotFather):

```
/newbot
Amiri
amiri_expenses_bot      ← имя должно быть свободным и заканчиваться на bot
```

BotFather пришлёт строку вида `123456789:AAH...` — это `BOT_TOKEN`.

### 3. Получить ключ OpenAI

На [platform.openai.com](https://platform.openai.com/api-keys) создайте ключ
(`sk-...`) и пополните баланс — хватит пары долларов.

Без ключа бот тоже работает: категории определяются словарём, но фото чека и
свободный текст («потратил триста на кофе») распознаваться не будут.

### 4. Создать базу

```bash
psql -U postgres -c "CREATE DATABASE amiri;"
```

Если `psql` не в PATH — создайте базу `amiri` любым клиентом (pgAdmin,
DBeaver) или полным путём:
`"C:\Program Files\PostgreSQL\17\bin\psql.exe" -U postgres -c "CREATE DATABASE amiri;"`

### 5. Backend — бот и API

```bash
cd backend
cp .env.example .env
```

Откройте `backend/.env` и заполните четыре строки:

```env
BOT_TOKEN=123456789:AAH...
OPENAI_API_KEY=sk-...
DATABASE_URL=postgresql+asyncpg://postgres:ВАШ_ПАРОЛЬ@localhost:5432/amiri
JWT_SECRET=<64 случайных символа>
```

Секрет сессии удобно получить так:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Дальше:

```bash
py -m venv .venv

source .venv/Scripts/activate      # Git Bash
# .\.venv\Scripts\Activate.ps1     # PowerShell
# source .venv/bin/activate        # Linux / macOS

pip install -r requirements.txt

alembic upgrade head          # создаст 7 таблиц
python -m app.db.seed         # 10 системных категорий

uvicorn app.main:app --reload
```

Должно появиться:

```
✓ категорияҳо: 10 нав, 10 ҳамагӣ
INFO  [amiri] Бот дар реҷаи polling
Run polling for bot @amiri_expenses_bot
```

Проверка: http://localhost:8000/health → `{"status":"ok","bot":"polling",...}`

### 6. Frontend — панель

Во **втором терминале**:

```bash
cd frontend
cp .env.example .env       # менять ничего не нужно
npm install
npm run dev
```

Панель: http://localhost:5173

### 7. Проверить

Напишите боту `/start`, потом `кофе 350`. Затем `/panel` — бот пришлёт
ссылку входа в панель.

## Переменные окружения

Два файла: `backend/.env` и `frontend/.env`. Оба создаются из `.env.example`
рядом и **в git не попадают** — это первая строка `.gitignore`.

### backend/.env

Обязательные — четыре:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | Токен от [@BotFather](https://t.me/BotFather) |
| `OPENAI_API_KEY` | Ключ OpenAI, `sk-...` |
| `DATABASE_URL` | `postgresql+asyncpg://пользователь:пароль@хост:порт/amiri` — драйвер обязательно `asyncpg` |
| `JWT_SECRET` | Подпись сессии панели, 64 символа |

Остальные имеют рабочие значения по умолчанию:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `OPENAI_MODEL` | `gpt-4o-mini` | Модель для категорий, свободного текста и чеков |
| `JWT_TTL_DAYS` | `7` | Сколько дней живёт вход в панель |
| `MAGIC_TOKEN_TTL_MINUTES` | `5` | Сколько живёт ссылка из `/panel` |
| `PANEL_URL` | `http://localhost:5173` | Адрес панели: CORS, ссылка входа, Mini App |
| `BOT_MODE` | `polling` | `polling` локально, `webhook` на сервере |
| `PUBLIC_URL` | `http://localhost:8000` | Публичный адрес backend, нужен для webhook |
| `WEBHOOK_SECRET` | `change-me` | Часть пути вебхука, случайная строка |
| `DEFAULT_LANG` | `ru` | Язык, если Telegram не сообщил свой |
| `DEFAULT_CURRENCY` | `TJS` | Базовая валюта нового пользователя |
| `DEFAULT_TZ` | `Asia/Dushanbe` | От часового пояса зависят границы «сегодня» |
| `FX_API_URL` | `open.er-api.com` | Источник курсов валют |

### frontend/.env

Для локального запуска менять не нужно.

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `VITE_BOT_USERNAME` | `amiri_expenses_bot` | Кнопка «Открыть бота» на странице входа |
| `VITE_API_URL` | пусто | Адрес API. Пусто — запросы идут на `/api` того же домена |
| `VITE_API_TARGET` | `http://127.0.0.1:8000` | Куда Vite проксирует `/api` при разработке |

## Если что-то не работает

**`TelegramConflictError` или бот молчит.** Один токен — один запущенный бот.
Telegram не отдаёт обновления двум процессам сразу. Закройте второй запуск.

**`error while attempting to bind on address ('127.0.0.1', 8000)`.** Порт занят
прошлым запуском. Найдите и закройте процесс либо возьмите другой порт:
`uvicorn app.main:app --port 8001`.

**`ModuleNotFoundError: No module named 'fastapi'`.** Не активировано
окружение. Нужен `source .venv/Scripts/activate` — в начале строки появится
`(.venv)`.

**`python app/main.py` падает с `No module named 'app'`.** Так и должно быть:
`main.py` — часть пакета, а не самостоятельный скрипт. Запуск только через
`uvicorn app.main:app`.

**`getaddrinfo failed` при старте.** В `DATABASE_URL` неверный хост или
PostgreSQL не запущен.

**Панель показывает `401` на все запросы.** Ссылка входа одноразовая и живёт
5 минут. Отправьте боту `/panel` ещё раз.

**В боте не работает `/panel`-кнопка.** Telegram не принимает `localhost` в
кнопках-ссылках, поэтому локально бот присылает обычный текст со ссылкой.
На домене с HTTPS появятся кнопки и Mini App.

## Деплой одной командой

На сервере нужен только Docker. Три контейнера: PostgreSQL, бот с API и
nginx с собранной панелью.

```bash
git clone https://github.com/ismoil3/expenses.git
cd expenses
bash deploy/setup.sh              # .env со случайными секретами
nano .env                         # BOT_TOKEN и OPENAI_API_KEY
docker compose up -d --build
```

Панель — `http://<IP>:8348`, API и Swagger — `http://<IP>:8347/docs`.
Порты нестандартные, чтобы не столкнуться с занятыми на сервере; меняются
в `.env`.

Nginx панели проксирует `/api` и `/webhook/` на контейнер API — панель и
бэкенд оказываются на одном origin, поэтому cookie сессии работает без
оговорок, CORS не нужен и хватает **одного** домена.

**Домен и HTTPS.** По IP работает всё, кроме кнопок-ссылок и Mini App:
Telegram принимает в них только HTTPS. Если на сервере уже есть nginx:

```bash
sudo bash deploy/https.sh вашдомен.tj
```

Скрипт добавит отдельный vhost (чужие конфиги не трогает, перед `reload`
делает `nginx -t`), получит сертификат через certbot, переключит `.env` на
`BOT_MODE=webhook` и пересоздаст контейнер API. Если домен на Cloudflare,
на время выпуска сертификата оставьте запись **DNS only**.

**Обновление:** `git pull && docker compose up -d --build`. Миграции и
системные категории накатываются при старте контейнера.

## Структура

```
amiri/
├─ backend/               # бот + API + база
│  ├─ app/
│  │  ├─ bot/             # хендлеры, клавиатуры, тексты на 3 языках
│  │  ├─ api/             # роуты, схемы, зависимости
│  │  ├─ db/              # модели, сессия, сиды
│  │  └─ services/        # парсер, AI, категоризатор, валюты, лимиты
│  ├─ alembic/            # миграции
│  ├─ tests/
│  └─ .env.example
└─ frontend/              # веб-панель
   ├─ src/
   │  ├─ pages/           # обзор, расходы, настройки, вход
   │  ├─ components/      # графики, список, фильтры
   │  └─ lib/             # API-клиент, формат, иконки
   └─ .env.example
├─ deploy/               # setup.sh — .env и секреты, https.sh — домен
├─ docker-compose.yml    # база + бот с API + панель
└─ .env.example          # для деплоя; у каждого проекта свой для разработки
```

## Безопасность

- `.env` и любые `*.env` — в `.gitignore` с первого коммита. Секретов в
  репозитории нет
- Вход в панель: одноразовая ссылка из бота (живёт 5 минут) или Telegram
  Mini App с проверкой подписи `initData` по HMAC
- Сессия в httpOnly-cookie; JavaScript до неё не дотягивается
- Каждый запрос к данным фильтруется по владельцу — см. `backend/tests/test_isolation.py`
